# Online Retail Data Analysis

## Overview
This project explores an online retail dataset using Google Sheets. The aim is to identify patterns in transaction values, country performance, product rankings, and customer activity.

## Tools
- Google Sheets
- Spreadsheet formulas
- Pivot tables
- Data quality checks
- Charts and dashboard design

## Key Findings
- November 2011 had the highest recorded monthly transaction value.
- The United Kingdom accounted for the largest transaction value among the countries analyzed.
- Product rankings differed depending on whether products were compared by quantity or transaction value.
- Missing customer IDs limited the customer-level analysis.

## Data Quality
The analysis examined missing values, negative quantities, zero-value transactions, and unusual price adjustments.

## Methodology
Transaction value was calculated as:

`LineValue = Quantity × UnitPrice`

This is a preliminary transaction-value measure and should not be interpreted as verified net revenue or profit.

## Limitations
Some transactions require further investigation, and the exact duplicate check has not been fully verified.

## Tools and Skills Demonstrated
Google Sheets, data cleaning, exploratory data analysis, pivot tables, data visualization, and communicating analytical findings.
